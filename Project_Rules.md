# Règles du projet MoneyFlow

## Coûts

- Aucune fonctionnalité essentielle ne doit nécessiter une API IA payante.
- Aucun abonnement payant ne doit être obligatoire pour utiliser l'application.
- Le projet doit pouvoir fonctionner avec des services gratuits ou auto-hébergés.

## UX

- L'application est mobile-first.
- Ajouter une dépense doit être extrêmement rapide.
- L'utilisateur doit comprendre sa situation financière en quelques secondes.
- Les conseils ne doivent pas être intrusifs.

## Finance

- Le solde réel doit toujours représenter l'argent réellement présent sur le compte.
- Une prévision ne doit jamais modifier le solde réel.
- Un transfert entre deux comptes n'est pas une dépense.
- L'épargne n'est pas considérée comme de l'argent disponible pour les dépenses courantes.

## Confidentialité

- Les données financières d'un utilisateur sont privées.
- Un utilisateur ne doit jamais pouvoir accéder aux données privées d'un autre utilisateur.
- Les comptes partagés doivent uniquement être accessibles aux membres autorisés.
